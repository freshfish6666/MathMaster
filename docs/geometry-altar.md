# 几何祭坛与几何核心

几何祭坛 `mathmaster:geometry_altar` 是单方块、固定的几何持有者召唤装置，放在创造方块页；几何核心 `mathmaster:geometry_core` 是64堆叠材料，放在主体创造页。模型沿用批准概念图：灰青石材、中央方形凹槽、四角石柱、嵌套方形纹路。核心使用独立的蓝青色立方体物品模型。

## 使用

```mcfunction
/give @s mathmaster:geometry_altar
/give @s mathmaster:geometry_core 16
```

- 手持核心右键立即消耗1个，主副手均可；创造模式也实际消耗，以保证取消只返还已消耗的材料。
- 仪式持续80tick（正常20TPS下4秒），青色纹路全亮、方块照明10，凹槽中显示核心并释放逐渐增多的青色粒子。只增加粒子演出，不改变Boss动画、声音或音乐。
- 仪式期间任意玩家再次右键可取消，空手或持其他物品均可；核心返回取消者背包，背包满时掉在玩家身边。返还保留原物品组件，如自定义名称。
- 仪式结束在祭坛正上方生成1只几何持有者，然后回到空槽。没有附近存活Boss限制，没有额外重复挑战冷却。
- 请在祭坛正上方留出以祭坛为中心的3×4×3格净空。实际检查现有Boss完整1.75×3.625格身体箱与方块碰撞、世界边界和建筑高度；不检查其他生物，不强制加载邻近区块。
- 开始时空间不足、和平难度不会收取材料。结束时再检查；空间被堵、改为和平或生成事件被其他模组取消时，核心退还同维度在线发起者，否则掉在祭坛处。
- 祭坛沿用末地传送门框架的硬度−1、爆炸抗性3,600,000，并加入原版凋灵/末影龙破坏免疫标签，生存模式不能挖掘、普通爆炸不能破坏，活塞不能移动。创造模式仍可移除，不掉落祭坛本体；创造或命令移除仪式中的祭坛会返还暂存核心。右键取消仍可正常取回材料。
- 暂存物品、发起者UUID和剩余tick保存在新祭坛方块实体中。区块卸载/退出世界暂停，重载后继续，不补算离线时间。无新增自定义网络负载。

核心现在通过击杀几何构造体固定获得1个，见[几何构造体](geometry-construct.md)。祭坛已随[几何圣所](geometry-sanctuary.md)自然生成，场地两只几何构造体提供核心；核心配方及Boss战利品尚未设定。原N祭坛及其献祭、BGM保持不变。
