# 几何构造体

几何祭坛的前置守卫小怪，实体ID `mathmaster:geometry_construct`，刷怪蛋 `mathmaster:geometry_construct_spawn_egg`。在几何圣所由两个DATA标记随结构生成，不加入普通群系刷怪列表；也可用创造主体页刷怪蛋手动放置，实体不会因玩家走远普通消失，和平难度按敌对生物规则移除。

```mcfunction
/give @s mathmaster:geometry_construct_spawn_egg
/summon mathmaster:geometry_construct ~ ~ ~
```

## 外观与属性

灰青像素石壳、中间凹槽内的青色几何核心、四块独立悬浮碎片，沿用批准的激光小怪概念图。11个立方组件、128×128像素图集和对应透明全亮层；核心/石壳青色纹路在暗处可见，不增加实际方块照明。身体和碎片有轻微上下漂动，倾斜朝向实际激光方向；碎片仅装饰，整体一个1.375×1.375格身体受击/碰撞箱。

基础生命24点、护甲4点、击杀经验5。无重力和摔伤，无冲撞或近战招式；激光采用普通生物攻击伤害来源，兼容原版护甲、盾牌、无敌帧、难度缩放及伤害取消事件，不直接扣生命或增加污染。

## 激光与移动

- 16格内有视线发现最近的存活生存玩家，超过24格、死亡、换维度或切换创造/旁观丢失目标。距离为三维距离；首次发现每10tick检查。
- 未施法时，水平超过8格平滑追近，低于4格缓慢后退，其间悬停；高度趋向玩家身体中心，不要求双方同一Y轴，不穿方块。没有复杂迷宫寻路。
- 首次等待20tick；进入施法后停在原地，20tick（1秒）蓄力，核心与纹路渐亮、电火花逐渐增加，并显示无伤害细线预警。
- 蓄力时持续瞄准；发射瞬间锁定方向，持续20tick（1秒），玩家可以侧移躲开。结束后等待40tick（2秒）再开始下一次蓄力，等待期间允许移动。
- 激光最长20格、半径参数0.12格；视觉和判定共用起点、方向与被墙截断后的长度。逐tick检查非创造/旁观玩家接触，普通难度每次基础伤害4点（简单3、困难6），正常无敌帧下完整持续激光最多两次基础命中。实墙截断，放墙后立刻更新；不强制加载远处区块，不破坏地形或点火。
- 蓄力时失去视线取消；已发射激光方向保持，仍受墙体限制。丢失目标、死亡或重载清理激光；蓄力/发射状态不写入存档，不在加载后重播旧招。
- 暂使用轻量原版紫水晶蓄力/释放/受伤/死亡提示音，HOSTILE类别；没有专用BGM，也不修改Boss音效或BGM。

## 掉落与获取

死亡战利品表 `mathmaster:entities/geometry_construct` 固定1个几何核心，没有概率门槛或抢夺增量。保留原版 `doMobLoot`、死亡/掉落取消规则；没有只限玩家击杀的条件，不重复手动补发。核心原ID/组件及祭坛使用规则保持不变。

几何核心现在可由击杀小怪获取，祭坛遗迹的实际怪物数量/布置、自然生成与正式平衡仍待用户决定。

## 开发与检查

批准概念保存在 `dev-assets/geometry-construct/concept-01.png`；可编辑源为 `geometry_construct.bbmodel` 与 `geometry-construct-model-source.json`。生成器 `tools/models/create_geometry_construct.py` 只写新模型几何Mesh/纹理和软件预览，不覆盖手写模型动画，不重画概念图；实际组件与图集预览为 `build/geometry-construct-preview.png`，不是客户端截图。

`GeometryConstructCheck` 随collision隔离服务器运行，34项断言覆盖真实刷怪蛋/创造入口、精确蓄力与持续、锁位锁向/侧移/重入、无敌帧、持续激光被新墙截断、非同高瞄准/模型俯仰、难度与护甲/事件取消、平滑追逐/无高度漂移/墙体碰撞、创造与距离脱战、存档清理、真实死亡/取消死亡/抢夺III固定一核心/不重复掉落。既有Boss/祭坛及全部回归通过，检查方法及隔离代码清理见 `tools/README.md`。

客户端实际造型、纹路发光、悬浮和激光手感待用户试玩；此处服务端结果不代替游戏视觉验收。
