# MathMaster（数学大师）

![MathMaster 图标](src/main/resources/mathmaster.png)

MathMaster 是一个以数学问答、公理技能与遗迹探索为核心的 Minecraft 冒险模组。在 **1.3.0** 中，你可以通过答题增长智识，将研读笔记演绎成公理，探索遍布世界的遗迹，并挑战主世界首个Boss——几何持有者。

## 安装

| 项目 | 要求 |
|---|---|
| Minecraft Java Edition | 1.21.1 |
| NeoForge | 21.1.248及以上的兼容版本 |
| Java | 21 |
| 必需前置 | Curios NeoForge 9.5.1～9.x |

客户端和服务端都需要安装MathMaster与Curios。Jade、JEI、MadnessCore、MCphone和Touhou Little Maid为可选联动。

## 从答题开始

1. 制作一本数学书，将它放入**雕纹书架**。
2. 紧挨雕纹书架放置一个**普通书架**，中间不留空格。
3. 不潜行，右击普通书架，开始四选一答题。

一个普通书架可以连接多个雕纹书架；存在多本数学书时随机选择题库。手持数学书右击可查看统一手册，了解完成进度和后续玩法。

| 数学书 | 难度 | 完成后领取的笔记等级 |
|---|---:|---:|
| 启蒙数学手册 | 1 | 1 |
| 初阶数学手册 | 5 | 2 |
| 进阶数学手册 | 10 | 3 |
| 高等数学手册 | 20 | 4 |
| 对数学诚挚的爱 | 30 | 5 |

答对获得智识经验与物品奖励，答错可能受到惩罚。初始IQ为30～50，最高200；数学书和生物洞悉各有经验来源上限。题目支持中英文切换，两种语言共用完成进度。至少答对过一次的题目会被记录，全部完成后可在手册中领取对应研读笔记。

主手持**智识之镜**，对具有智识的生物按住右键进行洞悉；全部答对会记录成功洞悉的生物种类。对空气或方块持续使用2秒可查看自己的智识、经验和污染值。

## 演绎与使用公理

在**公理演绎台**放入研读笔记和对应材料，选择公理。将演绎后的笔记放进公理匣，再通过Curios装备，能力即可生效。

公理匣、神谕匣和真理之匣分别容纳3、6、9份笔记；同一匣子每个分类最多容纳一个主动公理。

| 分类 | 演绎材料 | 已实现的公理 |
|---|---|---|
| 算术 | 红石 | 皮亚诺公理、加法单位元、加法交换律、加法逆元 |
| 数论 | 铁锭 | 欧几里得素数无穷定理、算术基本定理、素数连击 |
| 逻辑 | 石英 | 数学归纳法、对合、回归 |
| 几何 | 末影珍珠 | 普莱费尔公理、测地线 |
| 混沌 | 灵虚锭 | 香农熵 |

默认**按住X**打开主动公理轮盘，**按C**施放；按键可在控制设置中修改。测地线支持点按瞬移和长按飞行，回归支持点按管理锚点和长按跃迁。被动公理装备后自动生效，具体效果与数值见游戏内介绍。

对合仍为实验技能。哥德尔第一不完备性定理目前仅为可演绎的占位公理，尚无技能效果。

## 主世界冒险

答题与演绎之外，你也可以通过探索推进成长：

**未完成传送门 → N类试炼 → 几何圣所 → 几何持有者 → 素锭**

- **未完成传送门**：主世界与下界均有自然生成的遗迹，各使用独立奖励箱。主世界箱子可能提供灵虚材料、公理用品和指向N类试炼的地图。
- **N类试炼**：四个试炼刷怪笼提供战斗，灵虚块底座使N祭坛自动进入血祭。完成20次有效贡献后，底座变为奖励箱，必出几何圣所地图和2～3个灵虚锭；遗迹补给箱另有独立奖励。
- **几何圣所**：击杀几何构造体，必定获得几何核心。用核心右击几何祭坛，4秒后召唤Boss；仪式期间再次右击可取消并返还核心，结束后可重复召唤。几何祭坛在生存模式无法破坏。
- **几何持有者**：悬浮移动的双阶段Boss，使用光环、牢笼、激光、追踪炸弹、十字波和独立大招。近战、远程与大招可并行释放，血量低于40%进入二阶段，配有专属血条、声音和阶段BGM。击败后掉落2～3个素锭。

自然结构在新生成的区域出现，不会补进已经探索过的区块。

### N祭坛的正常献祭

本人**有效IQ大于50，且成功洞悉至少5种不同生物**后，永久解锁正常献祭；死亡、重连或IQ下降不会重新锁定。血祭与奖励开箱不需要这一条件。

正常祭品包含求知、合意与亵渎之物：矿物可能带来低级神谕，考拉兹果实提供智识经验，素数核心指引未完成主世界传送门，部分祭品会招致惩罚。血祭根据附近玩家的平均有效IQ调整怪物效果，智识越高通常越容易完成。完整规则见[N祭坛](docs/n-altar.md)。

## 材料、生物与污染

**灵虚系列**包含五种工具、四件护甲、智识之镜，以及可互相转换的锭、粒和块。五种工具基础攻击力为对应下界合金工具+2；灵虚装备提供心流，每级临时增加5智识，学士帽额外提供10。完整灵虚护甲降低一级有效数字污染效果。

**素系列**包含素锭、素粒和素块，使用银白淡紫配色，支持9粒与1锭、9锭与1块互相合成。

**考拉兹树**有红、紫、蓝三种，按考拉兹数列自动生长和分叉，提供同色木材与果实。树苗提示：**请勿在家等重要场所200格内种植**。

**数字生物6～9**各有独立外观与战斗行为。数字5为可承托生物的巨型平台实验原型，暂不自然生成；数字5画作可从创造物品栏获取，普通画随机放置不会出现它。

**数字化污染**来自部分技能、数字生物和污染环境，累积满100会致死。佩戴污染计量仪可查看实时数值；污染较高时会出现符文和低语。成功睡过夜、附魔金苹果和加法单位元护盾可帮助管理污染。污染环境与净化规则见[污染说明](docs/digital-pollution.md)。

## 可选联动与扩展

JEI可查询公理演绎配方；Jade显示生物智识与洞悉状态；MCphone提供“学习通”答题入口；Touhou Little Maid加入学习工作模式；MadnessCore可为答题附加精神消耗与位阶奖励。详细版本和配置见[联动说明](docs/integrations.md)。

题库、生物智识、神谕和战利品可通过数据包调整。题库格式见[题库扩展](docs/quiz-banks.md)，神谕合集见[N祭坛说明](docs/n-altar.md#求知献祭与神谕)。代码联动使用公共API `com.freshfish.mathmaster.api.MathMasterApi`，机器契约见[integration-contract.json](docs/integration-contract.json)。

## 配置与管理员命令

服务端配置文件为 `mathmaster-server.toml`，包含生物智识开关、近战增伤、维度污染等级、N祭坛血祭数量与联动选项。使用首次启动生成的配置，退出世界后编辑并重启；服务端设置为准。已有存档若仍配置 `required_offerings = 15`，需手动改成20。

最高档答题物品奖励默认每位玩家每个Minecraft游戏日最多10次，超过后仍可获得经验和进度。奖励区间允许重叠。

以下命令需要权限等级2；`<玩家>`支持玩家名或目标选择器：

| 命令 | 作用 |
|---|---|
| `/mathmaster query <玩家> points` | 查询当前IQ等级内的经验 |
| `/mathmaster query <玩家> levels` | 查询IQ |
| `/mathmaster add <玩家> <数量> points` | 增加经验 |
| `/mathmaster add <玩家> <数量> levels` | 增加IQ |
| `/mathmaster set <玩家> <数量> points` | 设置当前等级内的经验 |
| `/mathmaster set <玩家> <数量> levels` | 设置IQ |

`add`与`set`省略最后一项时默认操作经验。IQ限制为30～200，`set points`必须小于升到下一级所需经验。
