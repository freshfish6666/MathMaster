# MathMaster（数学大师）

![MathMaster 图标](src/main/resources/mathmaster.png)

MathMaster 是一个面向 Minecraft 生存玩法的数学问答模组。玩家可以制作不同难度的数学书，将它们放入雕纹书架，并通过相邻的普通书架开始四选一答题。

## 运行环境

| 项目 | 版本 |
| --- | --- |
| Minecraft Java Edition | 1.21.1 |
| NeoForge | 21.1.248 |
| Java | 21 |
| MathMaster | 1.1.0 |
| 模组 ID | `mathmaster` |

客户端和服务端都需要安装本模组。使用其他 Minecraft 或 NeoForge 版本可能无法启动。

## 1.1.0 主要功能

- 五本数学书共用一份原版成书风格的“数学大师手册”，可查看教程、当前完成度和已掌握题目。
- 使用智识之镜长按洞悉具有智识的生物；题量与难度随目标智识变化，全部答对后记录生物种类并解锁相应成就。
- 玩家智识领先生物时获得可配置的减伤前近战增伤；洞悉和数学书经验均有来源上限，避免低难度内容无限提升 IQ。
- 灵虚工具会提供“心流”效果，每级临时增加 5 点智识；灵虚系列新增方块、粒和完整配方。
- 五本正式题库共含 611 道题，五个洞悉难度池共含 617 道题。

## 主要玩法

模组目前包含五种数学书：

- 启蒙数学手册，难度 1
- 初阶数学手册，难度 5
- 进阶数学手册，难度 10
- 高等数学手册，难度 20
- 对数学诚挚的爱，难度 30

书的难度决定答对后获得的智力经验。玩家初始 IQ 随机为 30～50，最高为 200；答对题目可以提升智力经验和 IQ。

每道题都有稳定标识。玩家至少答对过一次的题目会被记录，并显示在数学书名称后的“已完成/总数”中。最近答对的 10 道题会暂时排除，已经多次答对的题目抽取权重也会降低；完成一本书的全部题目可以获得对应进度。

《启蒙数学手册》和《对数学诚挚的爱》的配方会在玩家进入游戏时解锁；《初阶数学手册》《进阶数学手册》和《高等数学手册》分别在 IQ 达到 40、45 和 50 时解锁。未在配方书中解锁的配方仍可在材料摆放正确时合成。

答对后会按照题目难度与当前 IQ 从多个奖励区间中抽取物品，奖励区间可以重叠。达到最高奖励档时，每位玩家每个 Minecraft 游戏日最多领取 10 次完整物品奖励；超过次数后仍可继续答题并获得智力经验，但不会获得物品奖励。

答错可能没有额外影响，也可能受到伤害、失明、雷击或获得三猫奶粉。部分食物也会少量改变智力经验。

## 答题界面

第一次选择答案后，界面不会自动关闭。错误选项会显示红叉，正确选项会显示绿色对勾，玩家可以选择“下一题”或“退出”。作答结束后继续点击其他选项会播放额外音效，但不会改变答案结果。

答题界面会记录触发它的书架位置。玩家离开超过 4 格，或者对应书架被破坏后，界面会自动关闭。

## 灵虚系列

- 智识之镜：主手持有时可以洞悉生物；主手或副手持有时会显示当前 IQ 与经验进度。
- 灵虚锭：最高级答题奖励之一，也是灵虚系列物品的制作材料。
- 灵虚剑、镐、斧、锹和锄：耐久与攻击速度得到强化；除剑外的工具攻击力提高为原数值的 1.5 倍。
- 灵虚工具：每只手持有一件便提供一级“心流”，主副手同时持有时为二级。
- 灵虚块与灵虚粒：支持灵虚材料的压缩、拆分和储存。

灵虚工具具有防火属性，并可使用灵虚锭修复。制作灵虚之镜需要在工作台中央放置一个灵虚锭，并用玻璃围满周围八格。

## 如何搭建答题书架

1. 制作或从“数学大师”创造模式物品栏中取得一本数学书。
2. 放置一个雕纹书架，并将数学书放入其中。
3. 在雕纹书架任意相邻方向放置一个普通书架。两个书架必须直接相邻，中间不能留空格。
4. 不要按住潜行键，右击普通书架。
5. 游戏会从相邻雕纹书架中的数学书里随机选择题库，并打开四选一答题界面。

一个普通书架周围可以连接多个雕纹书架，也可以放入多本数学书。此时题库会从所有检测到的数学书中随机选择。

## 管理员命令

所有命令都需要权限等级 2。

| 命令 | 作用 |
| --- | --- |
| `/mathmaster query <玩家> points` | 查询玩家当前 IQ 等级内的智力经验 |
| `/mathmaster query <玩家> levels` | 查询玩家当前 IQ |
| `/mathmaster add <玩家> <数量> points` | 增加智力经验 |
| `/mathmaster add <玩家> <数量> levels` | 增加 IQ |
| `/mathmaster set <玩家> <数量> points` | 设置当前 IQ 等级内的智力经验 |
| `/mathmaster set <玩家> <数量> levels` | 设置 IQ |

`add` 和 `set` 省略最后的 `points` 或 `levels` 时，默认操作智力经验。`<玩家>` 支持 Minecraft 目标选择器，例如 `@a`、`@p` 或玩家名。

IQ 会被限制在 30～200。`set points` 的值必须小于当前 IQ 升到下一级所需的经验值。

## 配置

1.1.0 首次启动世界或服务器后，NeoForge 会生成带注释和数值范围说明的：

```text
config/mathmaster-server.toml
```

服务器也可以在 `world/serverconfig/mathmaster-server.toml` 放置世界专用配置。服务端配置是最终权威，并会同步给加入服务器的客户端。编辑后建议重启世界或服务器，以确保所有值完成重载。

默认配置的主要部分如下：

```toml
[entity_intellect]
enabled = true

[entity_intellect.damage_bonus_percent]
lead_1_to_20 = 5.0
lead_21_to_40 = 15.0
lead_41_to_60 = 25.0
lead_61_to_80 = 30.0
lead_81_plus = 40.0
```

- `enabled = false`：关闭整套生物智识玩法，包括智识之镜洞悉、生物洞悉经验与记录、以及智识领先近战增伤；已有玩家记录不会被删除。
- 五个 `lead_*` 值是百分数，例如 `15.0` 表示伤害乘以 `1.15`。
- 增伤作用于本次攻击已有的伤害，并发生在盾牌、护甲、防护附魔和抗性等减伤之前。
- 配置会限制百分比为 `0.0～1000.0`，无效值由 NeoForge 配置系统纠正。

IQ 范围、初始 IQ、奖励表和防沉迷参数目前仍由源码控制。题目与生物智识定义不需要修改源码，可以通过 JSON 数据包扩展或覆盖。

## 生物智识与其他模组兼容

MathMaster 使用注册表 ID 和数据包读取生物智识，不直接引用其他模组的实体类。整合包作者可以创建：

```text
data/<你的命名空间>/entity_intellect/<文件名>.json
```

为任意已安装模组的生物设置智识：

```json
{
  "entity": "othermod:example_creature",
  "intellect": 80,
  "enabled": true
}
```

- `entity` 必须是目标生物的完整注册表 ID。
- `intellect` 必须是大于或等于 0 的整数。
- 将 `enabled` 设为 `false` 可以移除同一实体此前加载的智识定义。
- 多个定义按资源 ID 排序加载；后加载的同一实体定义会覆盖先加载的值。
- 放入世界 `datapacks` 目录后执行 `/reload` 即可重载。

智识增伤默认只处理满足以下条件的伤害：

1. 伤害类型位于原版 `minecraft:is_player_attack` 标签中。
2. 伤害来源实体和直接实体都是攻击玩家，因此不会误作用于箭矢、宠物、荆棘或机器伤害。
3. 受击生物存在有效的智识定义。

其他模组若使用自定义直接近战伤害类型，只需通过数据包把该伤害类型加入 `minecraft:is_player_attack`，无需让 MathMaster 直接依赖该模组。若某种特殊玩家伤害不应获得智识加成，可将它加入 MathMaster 的排除标签：

```text
data/mathmaster/tags/damage_type/no_intellect_damage_bonus.json
```

```json
{
  "replace": false,
  "values": [
    "othermod:special_player_damage"
  ]
}
```

代码联动时可调用 `EntityIntellectManager.get(entity)` 查询目标当前有效智识：只有配置过智识的实体才会返回定义，心流效果会在基础值上每级增加 5 点；无智识定义的实体即使带有心流效果也仍返回 `null`。玩家当前有效 IQ 可通过 `IntelligenceManager.getEffectiveIq(player)` 读取。除非需要编译期 API，不建议直接引用其他模组的实体类；优先使用上述数据包接口。

洞悉开始、持续、难度门槛和题库选择均由服务端加载的智识定义权威判定。客户端无需拥有服务端或整合包提供的同一份 `entity_intellect` 数据包；服务端拒绝洞悉时会把本次目标智识与玩家有效 IQ 发送给客户端显示。

## 题库扩展

题库文件位于数据包的：

```text
data/<命名空间>/quiz_banks/<题库名>.json
```

可用题库名如下：

| 文件名 | 对应数学书 |
| --- | --- |
| `grade_2.json` | 启蒙数学手册 |
| `junior_high.json` | 初阶数学手册 |
| `senior_high.json` | 进阶数学手册 |
| `advanced.json` | 高等数学手册 |
| `millennium_problems.json` | 对数学诚挚的爱 |

示例：

```json
{
  "replace": false,
  "questions": [
    {
      "id": "addition_001",
      "question": "2 + 2 = ?",
      "correct_answer": "4",
      "wrong_answers": ["2", "3", "5"]
    }
  ]
}
```

规则：

- `replace: false` 表示将题目追加到对应题库。
- `replace: true` 表示加载该文件时先清空对应题库。
- `id` 是可选但强烈建议填写的稳定题目标识，同一题库内不得重复。
- 每道题必须有非空题干、一个正确答案和恰好三个错误答案。
- 四个答案必须互不相同，同一题库内不能出现重复题干。
- 无效题目会被跳过，具体原因会写入服务端日志。
- 使用 `mathmaster` 命名空间和相同文件路径可以覆盖内置文件。
- 使用其他命名空间及上述文件名，可以向对应题库追加题目。

将数据包放入世界的 `datapacks` 目录后，执行 `/reload` 即可重新加载题库，无需重新编译模组。更完整的格式说明见 [`docs/quiz-banks.md`](docs/quiz-banks.md)。

## 从源码构建

需要使用 Java 21 和项目自带的 Gradle Wrapper：

```powershell
.\gradlew.bat build
```

构建产物位于：

```text
build/libs/mathmaster-1.1.0.jar
```
